# ISO/IEC 42001:2023 — Requirements Traceability Matrix

> **Current as of:** March 2026 | ISO/IEC 42001:2023

## Purpose

This matrix ensures every ISO 42001 requirement is addressed by at least one template in the toolkit. It is the acceptance test for toolkit completeness. When all entries reach "Covered" status, the toolkit is ready for a certification engagement.

## How to Read This Matrix

**Columns:**

| Column | Meaning |
|--------|---------|
| Clause/Control ID | The ISO 42001 clause number or Annex A control identifier |
| Requirement Description | Short title of what the clause or control requires |
| Template(s) | Toolkit file(s) planned to address this requirement |
| Section | Specific section within the template (TBD until verified) |
| Status | Current coverage state (see below) |

**Status values:**

- **Planned** — Template identified but not yet verified against the actual requirement text
- **Covered** — Template exists and has been verified to address the requirement (set during Task 27 verification)
- **Gap** — No template addresses this requirement (target: zero at toolkit completion)
