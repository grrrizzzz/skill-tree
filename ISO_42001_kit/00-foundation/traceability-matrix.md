# ISO/IEC 42001:2023 — Requirements Traceability Matrix

> **Current as of:** March 2026 | ISO/IEC 42001:2023

## Purpose

This matrix ensures every ISO 42001 requirement is addressed by at least one template in the toolkit. It is the acceptance test for toolkit completeness and a consultant reference tool — use it to answer "which file do I use for Clause 6.1.4?" or "what does the SoA template cover?"

## How to Read This Matrix

**Status values:**

- **Planned** — Template identified but not yet verified against the actual requirement text
- **Covered** — Template exists and has been verified to address the requirement
- **Gap** — No template addresses this requirement (target: zero at toolkit completion)

**Document Type codes:**

- **Procedure** — Internal consultant procedure (how to run the engagement)
- **Template** — Client-facing deliverable template
- **Reference** — Internal reference document (not a deliverable)
